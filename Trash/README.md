# Trash

Carpeta de descarte controlado para mantener el proyecto operativo limpio.

## Propósito

- Guardar material legado o no usado por la ejecución actual.
- Evitar borrar definitivamente elementos históricos.
- No usar estos archivos como dependencia de frontend, backend o base de datos.

## Subcarpetas

- `legacy-angular/`: intentos de migración Angular archivados.
- `orphans/`: archivos sueltos detectados fuera del flujo actual.
- `backups/`: respaldos locales pesados (`.tar.gz`).
- `reports/`: reportes temporales de limpieza.
